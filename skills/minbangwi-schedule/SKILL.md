# 민방위 교육일정 조회

국민안전24(safekorea.go.kr)의 민방위 교육일정 페이지를 조회해서 교육 날짜·시간·장소·대상·담당부서 연락처를 가져온다.

## 쓰는 법

모든 기능은 `scripts/minbangwi.py`로 돌아간다(달력 그리기만 옆의 `svgcal.py`). 파이썬 3.9+ 표준 라이브러리만 쓰므로 설치할 패키지가 없다.

```bash
python scripts/minbangwi.py <하위명령> [옵션]
```

### 1. 교육일정 조회 — `schedule`

행정구역은 **시도 / 시군구 / 읍면동 어느 단계로 줘도 된다.** 공백으로 구분된 자유 문구로 넘기면 된다.

```bash
# 읍면동 — 그 동 하나만
python scripts/minbangwi.py schedule 서울특별시 종로구 사직동 --from 2026-11-01 --to 2027-01-31

# 시군구 — 그 구의 모든 동
python scripts/minbangwi.py schedule 종로구 --from 2026-11-01 --to 2026-11-30

# 시도 — 그 시도의 모든 시군구 (아래 "시도 전체 조회" 참고)
python scripts/minbangwi.py schedule 서울특별시 --from 2026-11-15 --to 2026-12-15 --summary

# 교육대상 / 교육시간으로 거르기
python scripts/minbangwi.py schedule 서울 강남구 --target 31 --time 2

# 구조화된 결과가 필요할 때
python scripts/minbangwi.py schedule 수원시 영통구 --json
```

- `서울 종로구 사직동`, `세종 반곡동`, `종로구`, `서울` 모두 된다. 하나로 좁혀지지 않으면 후보 목록을 출력하고 종료코드 1로 끝난다. 그때는 후보 중 하나를 골라 다시 부르거나 사용자에게 되묻는다.
- 결과는 **항상 교육일시(날짜 → 시작시각) 순으로 정렬**되어 나온다.
- `--from` / `--to` 기본값은 오늘 ~ 한 달 뒤다. 사이트가 **최대 3개월 범위**만 지원하므로 그보다 길면 경고가 나오고 결과가 잘릴 수 있다. 긴 기간은 3개월씩 나눠 여러 번 조회한다.
- 담당부서 연락처는 자동으로 붙는다. 필요 없으면 `--no-contact`(조회가 꽤 빨라진다. 시도 전체 조회에서 특히).
- 페이지네이션은 스크립트가 알아서 끝까지 돈다.

#### 시도 전체 조회

원래 사이트는 **시군구가 필수**라 시도 단위 조회가 없다. 그래서 시도만 주면 스크립트가 `regions`로 그 시도의 시군구 목록을 뽑아 **시군구마다 한 번씩 조회한 뒤 합치고 날짜순으로 정렬한다.** 별도 API가 아니라 기존 조회를 반복하는 것뿐이다.

- 각 행에 어느 구인지 알 수 있게 `시군구` 열이 붙는다.
- 진행상황이 stderr로 찍힌다(`[ 7/25] 중랑구 0건`). 끄려면 `--quiet`.
- 시군구 수만큼 요청이 나가므로 서울·경기는 1~3분쯤 걸린다. 미리 "25개 구를 차례로 조회하는 중"이라고 알리고 기다린다.
- 세종특별자치시는 시군구 단계가 없어 그냥 한 번만 조회한다.

#### `--summary` — 교육회차로 접기

시도 전체를 조회하면 수백 건이 나오는데 대부분은 **한 교육회차에 여러 행정동이 묶인 것**이다(같은 날 같은 장소 같은 시간). `--summary`는 이걸 한 줄로 접어서 날짜별로 보여준다. 서울 한 달치 기준 471건 → 89개 회차.

```
## 2026-11-17
  09:00 ~ 13:00  송파구  기본교육 보충2차 / 민방위대 편입 1~2년차 대원
      송파여성문화회관 6층 실벗뜨락(유료주차)
      대상 8개동: 가락1동 가락2동 ...
```

시도나 큰 시군구를 조회할 때는 `--summary`를 기본으로 쓴다. 특정 동의 일정만 궁금한 거라면 그 동을 직접 지정하는 쪽이 훨씬 빠르다.

#### 교육장소 — 주소와 지도 링크

표 아래에 교육장이 각주로 한 번씩 붙는다. 같은 장소가 수십 줄 반복되므로 줄마다 주소를 적지 않고 번호(`[1]`)로만 가리킨다.

```
교육장소
  [1] 마포구청 2층 대강당(유료주차)
      서울특별시 마포구 월드컵로 212 (성산동, 마포구청)
      https://safekorea.go.kr/safekorea-kor/flsm/flsm/miniMap.do?juso=...&title=...
```

- 링크는 사이트에서 교육장소를 눌렀을 때 열리는 것과 **완전히 같은 URL**이다.
- 사이버교육이면 지도 대신 교육 사이트 주소(`https://kcmes.kr/`)가 나온다.
- 도로명주소가 없는 교육장은 사이트에서도 지도가 안 열리므로 링크가 비어 있다.
- `--json`에는 각 일정마다 `주소`·`링크` 필드가 들어간다. 사용자가 "어디서 하냐"고 물으면 장소명만 말하지 말고 주소와 링크를 같이 준다.

#### `--calendar OUT.svg` — 달력으로 그리기

"언제 뭐가 있나"를 한눈에 보려면 표보다 달력이 낫다. 조회 결과를 그대로 월별 달력 SVG로 떨군다.

```bash
python scripts/minbangwi.py schedule 서울특별시 --from 2026-11-15 --to 2026-12-15 \
    --no-contact --quiet --calendar seoul.svg
```

- 날짜 칸에 `강남오전` `성북야간` `마포오후` 식으로 적는다. 시도 전체 조회면 **시군구 이름**, 시군구/읍면동 조회면 **행정동 이름**을 쓴다.
- 같은 날 같은 지역의 같은 시간대는 한 줄로 합친다(교육장이 여러 곳이어도 한 줄).
- 시간대는 시작시각 기준 — 12시 전 `오전`, 18시 전 `오후`, 그 뒤 `야간`, 사이버교육·종일과정은 `온라인`. 색은 이 네 가지를 나타내는 보조 표시이고 글자에 이미 적혀 있다.
- 조회 기간 밖 날짜는 흐리게 칠한다. 다크모드도 따라간다.
- **각 항목은 교육장 위치 링크가 걸린 하이퍼링크다.** 눌러서 바로 지도를 열 수 있다. 한 항목에 교육장이 둘 이상 묶이면 어디로 보낼지 알 수 없으므로 링크를 안 건다.
- **사용자에게 결과를 보여줄 때 이 SVG를 같이 보내면 좋다.** 수백 건짜리 표를 늘어놓는 것보다 훨씬 잘 읽히고, 토큰도 덜 쓴다.

### 2. 행정동 검색 — `regions`

사용자가 동 이름만 말했거나, 같은 이름의 동이 여러 시도에 있을 때 쓴다.

```bash
python scripts/minbangwi.py regions 사직            # 이름 조각으로 전국 검색
python scripts/minbangwi.py regions --sido 서울특별시 --sgg 종로구 --level dong   # 종로구 읍면동 목록
python scripts/minbangwi.py regions 수원 --level sgg --json
```

출력 열: 전체 행정구역명, 구분(시군구/읍면동), 조회용 코드(`orgCd`), 법정동코드(`arcd`).

### 3. 코드표 — `codes`

```bash
python scripts/minbangwi.py codes
```

| `--target` | 교육대상 | | `--time` | 교육시간 |
|---|---|---|---|---|
| `10` | 민방위대 | | `0` | 평일교육 |
| `20` | 신편대원 | | `1` | 야간교육 |
| `31` | 민방위대 편입 1~2년차대원 | | `2` | 주말교육 |
| `32` | 민방위대 편입 3~4년차대원 | | | |
| `33` | 민방위대편입 2년차대원 | | | |
| `50` | 자체교육인정자 | | | |
| `60` | 민방위대 편입 5년차 이상 | | | |

### 4. 지역 코드표 갱신 — `refresh-regions`

`assets/regions.json`(시도 16건 + 시군구·읍면동 4,072건)을 사이트에서 다시 받아 덮어쓴다. 행정구역 개편으로 "찾지 못했습니다"가 날 때만 실행한다.

```bash
python scripts/minbangwi.py refresh-regions
```

## 응답할 때

- 표를 그대로 붙여넣지 말고 사용자가 물은 것만 추린다. 보통은 **가장 빠른 교육일 1~3건**과 장소, 교육대상이면 충분하다.
- 장소를 말할 때는 **주소와 지도 링크를 같이** 준다. 장소명만으로는 찾아갈 수 없다.
- 교육장소가 `민방위 사이버 교육센터(https://kcmes.kr/)`로 나오면 온라인 사이버교육이다. 링크를 알려준다.
- 민방위 교육은 주민등록지가 아닌 현 거주지에서도 받을 수 있다. 다만 거주지 교육일정을 검색했다면 **거주지 관할 시·군·구청 민방위 담당자에게 확인**해야 한다는 안내가 원 사이트에 있으므로, 결과가 애매하면 함께 나온 담당부서 연락처를 알려준다.
- 조회 결과가 0건이면 **기간을 넓혀 한 번 더 확인하고 답한다.** 조회가 실패한 건지 정말 일정이 없는 건지 구분이 안 되기 때문이다. 넓혀서 결과가 나오면 "그 기간엔 없고 언제언제 있다"고 알려준다.
- 지자체마다 일정을 올리는 시점이 달라서 한두 달 앞까지만 등록돼 있는 경우가 흔하다. 먼 미래가 비어 있으면 아직 안 올라온 것일 수 있다고 덧붙인다.

## 동작 방식 (참고)

- 일정: `GET https://safekorea.go.kr/safekorea-kor/edtr/clns/escd/educationSchedule.do`
  — `q_area_cd_1`(시도), `q_area_cd_2`(시군구), `q_area_cd_3`(읍면동), `q_strdate`/`q_enddate`(YYYYMMDD), `currentPage`, **`pageIndex`**(이게 빠지면 빈 결과가 돌아온다), `edcTgtSeCd`, `hdaySe`. 페이지당 10건.
- 연락처: `POST .../edtr/clns/dcif/departmentContactInformationJson.do` — `sbLawArea1/2/3`, JSON 응답.
- 지역 코드표는 일정 페이지 HTML에 `data.push({...})`로 인라인되어 있다. `refresh-regions`가 이걸 긁는다.
- 세종특별자치시는 시군구 단계가 없어 시도 코드(`5690000`)를 시군구 코드로도 쓴다. 스크립트가 처리한다.
- `q_area_cd_2`(시군구)는 필수다. 비우면 결과가 안 나온다. 시도 전체 조회가 시군구를 순회하는 이유다.
- 원본 데이터에 모든 칸이 빈 레코드가 가끔 섞여 나온다(교육일시가 `: ~ :`). 파서가 버린다.
- 교육장소 링크: 사이트는 `onMoveMap(juso, title)`로 `flsm/flsm/miniMap.do?juso=…&title=…`을 연다. 확인해 보니 `juso`는 **도로명주소**, `title`은 **교육장소**로, 둘 다 `viewDetale`에서 이미 뽑고 있는 값이다. 그래서 `onMoveMap`을 따로 긁지 않고 그 두 필드로 URL을 만든다. 인코딩은 `encodeURIComponent`와 맞춰야 사이트와 같은 URL이 된다(`-_.!~*'()`는 인코딩하지 않음).
- 장소명 안에 URL이 있으면 사이트는 지도 대신 그 URL을 연다. 사이버교육이 이 경우다.
